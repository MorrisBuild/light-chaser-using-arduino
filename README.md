# Arduino Light Chaser

A simple Arduino Uno project that creates a running light effect using 12 LEDs.

## Components Used

- Arduino Uno R3
- Breadboard (400 points)
- 12 x 5mm Rectangular LEDs
- 12 x 220Ω Resistors
- Male-to-Male Jumper Wires
- USB Type-B Cable
- USB-C OTG Adapter (for ArduinoDroid)

## Features

- 12 LED sequential chasing pattern
- Beginner-friendly project
- Easy to customize
- Upload code directly from Android using ArduinoDroid

## Pin Configuration

LED1 → D2  
LED2 → D3  
LED3 → D4  
LED4 → D5  
LED5 → D6  
LED6 → D7  
LED7 → D8  
LED8 → D9  
LED9 → D10  
LED10 → D11  
LED11 → D12  
LED12 → D13
